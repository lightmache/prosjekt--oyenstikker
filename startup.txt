# Prosjekt Øyenstikker — Startup Guide

## Every time you start

### 1. Open terminal and get into WSL
In Command Prompt or PowerShell:
    wsl

### 2. Navigate to project
    cd /mnt/d/Projects/memory-system
    source venv/bin/activate

### 3. Start the database
    sudo docker compose up -d

### 4. Start the API server (first terminal)
    uvicorn fuse:app --reload

Wait for:
    INFO: Application startup complete.

### 5. Open a second terminal for queries
    wsl
    cd /mnt/d/Projects/memory-system
    source venv/bin/activate

## Test commands

### Store a memory
    curl -X POST http://localhost:8000/ingest -H "Content-Type: application/json" -d '{"content": "your text here", "metadata": {"type": "note"}}'

### Search memories
    curl "http://localhost:8000/search?q=your search query"

### Ask a question (RAG)
    curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d '{"q": "your question here"}'

## Models available in Ollama
    ollama list

## Check database is running
    sudo docker ps

## Stop everything
    sudo docker compose down
    Ctrl+C in the uvicorn terminal
