IDENTIFIER urn:nasa:pds:ladee_ldex:data_derived::2.0
NAME data_derived collection for the "LADEE LUNAR DUST EXPERIMENT" bundle
TYPE Data
DESCRIPTION This is the data_derived collection for the ladee_ldex bundle. This archive bundle includes data taken by the Lunar Dust Experiment (LDEX) instrument aboard the Lunar Atmosphere and Dust Environment Explorer (LADEE) spacecraft. These data are generated by dust impacts on the LDEX detector. Both reduced and calibrated data are included in this bundle.
